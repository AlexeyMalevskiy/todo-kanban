# 📋 Канбан-доска (To-Do лист)

Интерактивный менеджер задач с возможностью перетаскивания (Drag-and-Drop), написанный на чистом JavaScript.

## Возможности
- Добавление и удаление задач.
- Три колонки: «В планах», «В работе», «Сделано».
- Перетаскивание задач между колонками (Drag-and-Drop API).
- Автоматическое сохранение задач в LocalStorage (не пропадают при перезагрузке).
- Переключатель тёмной и светлой темы с сохранением выбора.
- Адаптивный дизайн (на телефоне колонки выстраиваются в столбик).
- Полная поддержка мобильных устройств (перетаскивание задач пальцем).

## Технологии
- HTML5 (Drag-and-Drop API)
- CSS3 (Grid, Flexbox, CSS Variables)
- Vanilla JavaScript (DOM, LocalStorage)
